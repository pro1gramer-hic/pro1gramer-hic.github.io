Administration du portfolio

Ajoute ou modifie tes projets, compétences, certifications et textes. Chaque publication met à jour le site en une à deux minutes.

Comment créer le jeton (une seule fois)
  1. Sur GitHub, ouvre ta photo de profil en haut à droite, puis Settings.
  2. Tout en bas du menu de gauche : Developer settings, puis Personal access tokens, puis Fine-grained tokens.
  3. Clique sur Generate new token. Donne-lui un nom (« Admin portfolio ») et une date d'expiration.
  4. Dans Repository access, choisis Only select repositories et sélectionne le dépôt de ton site.
  5. Dans Permissions, ligne Contents, choisis Read and write.
  6. Clique sur Generate token, copie le jeton (il commence par github_pat_) et colle-le ici.

Le jeton reste dans ce navigateur. Ne le partage avec personne : il permet de modifier ton site.
